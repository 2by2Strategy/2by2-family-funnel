# 2by2 Academy – Family Matchmaking Funnel

- `index.html` – landing page (hero, trust bar, "Matchmaking call for your student" → Get started)
- `quiz.html` – the 10-question matchmaking questionnaire

## Before running ads
Edit the SETTINGS block at the top of the `<script>` in each file:
- `quiz.html`: `BOOKING_URL` (2by2 calendar link), `WEBHOOK_URL` (GoHighLevel inbound webhook)
- `index.html`: `PROOF` (rating, families matched, family photos)

Hosted with GitHub Pages from the `main` branch.
